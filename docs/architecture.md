# 系统架构
此图描述已维护的原系统。公开仓库未部署完整分析服务。

~~~mermaid
flowchart LR
    U[React 前端] --> A[FastAPI 视频 API]
    A --> D[(任务状态与产物索引)]
    A --> W[异步 Worker]
    W --> P[Step1 视频预处理]
    P --> S[独立 ASR HTTP 服务]
    P --> I[结构化课堂输入]
    I --> M[Step2 指标与模型分析]
    M --> V[结构及一致性校验]
    V --> R[报告 / 图表 / 证据]
    R --> U
~~~

ASR 与模型是外部可配置服务。示例不接入它们，真实视频、数据库和凭据留在私有环境。
生产维护分为前端、Step2 后端（含分析包）、Step1、部署四仓库。
本展示取自历史 0.4.15 分支记录，不混入后续其他版本和模块实验指标。
