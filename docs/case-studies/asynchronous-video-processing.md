# 异步视频处理

## 问题

视频预处理、ASR与分析耗时较长。页面需要展示阶段进度，离开后仍能查看历史；取消或失败时，也要知道处理停在哪一步。

## 原因

页面连接的生命周期短于分析任务。只靠一次请求或一个完成百分比，无法完整表达任务状态、阶段产物和失败原因。

## 处理

~~~text
接收任务 → 预处理 → 输入校验 → 分析 → 报告交付
~~~

任务状态与产物索引持久化，Worker执行阶段工作，前端查询状态与结果。任务目录、并发和所有权由后端管理，取消与失败保留阶段信息。

| 判断 | 行为 |
| --- | --- |
| 任务独立于页面连接 | 离开页面后仍可查询进度和历史 |
| 阶段与终态分开 | 区分已接收、分析完成和交付失败 |
| 执行状态与评价范围分开 | 任务完成后，证据不足的指标仍显示待确认 |
| 失败保留上下文 | 记录失败阶段及可用产物，支持定位问题 |

## 验证

[平台历史验收](../validation.md)包含任务状态、报告产物和结果接口检查。取消竞态、跨进程恢复与并发隔离不在该记录覆盖范围内。

任务与报告的连接见[架构图](../architecture.md)，评价状态的计算与显示见[证据案例](evidence-aware-scoring.md)。
