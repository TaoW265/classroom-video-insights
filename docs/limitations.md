# 适用范围

- `scope`来自输入元数据，聚合函数不从音视频中判定证据是否可靠。
- `directional`信号按原权重参与计算，未进行置信度校准。
- 部分可评价的分数只描述纳入项；输入项比例不等于课堂时长或学生人数覆盖率，覆盖范围不同的分数不宜直接排序。
- 缺少`scope`或`evaluation`的旧数据沿用兼容行为，原有证据质量不会因此得到重新确认。
- 行为测试验证计算和显示规则，截图中的评分、模式与文字也不能单独证明教学评价准确性。
- 内容检查覆盖指定文件类型、敏感标识、素材哈希和引用，不能替代完整安全或隐私审查。

计时样本的范围见[历史性能记录](performance.md)，分发范围见[许可说明](license-review.md)。
