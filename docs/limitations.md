# 展示范围与限制

本仓库分别展示实际前端素材与独立代码示例。截图和录屏来自用户提供的已有报告界面；合成信号、聚合函数、显示函数与测试为公开示例，不是前端源码，也不生成素材中的真实报告。

展示版素材经过裁切，去除学校和源文件名等身份信息、历史列表及课堂画面，录屏去除音轨。原始文件只保留在本机素材目录并排除交付。本次编辑版本由仓库所有者授权发布到公开作品集，范围限于素材清单中的文件；原始素材、额外课堂材料与第三方权利不据此扩展。裁切与内容检查不是完整隐私或法律认证。

截图中的分数、指标、课堂模式和文字，是录制时已有结果的界面表现。本次没有重新分析课程，也未验证这些教学评价的准确性；不能将界面可见推导成完整平台、当前后端或全部课堂分析均已通过验收。

原平台核心代码被合作团队用于尚在内测的产品。完整生产源码、课堂音视频原件、转写文件、数据库、内部配置与日志不在公开代码范围。展示前端截图不等于其源码获准公开。

公开代码只演示证据范围、加权与显示。它没有完整量表、Worker、ASR、模型服务、角色识别或生产交付协议，也不修改原系统JSON协作规范。四个合成场景不构成课堂评价准确率或模型稳定性证据。

`scope`由合成输入明确给出，程序不负责判定证据真伪。部分信号纳入的比例不是课堂覆盖率；旧输入的兼容行为也不等于对旧证据的重新认证。

[职责说明](contributions.md)区分公开可核验内容与尚未细分的原系统维护职责。[性能记录](performance.md)是两个历史任务的摘要，不是本次重跑结果或完整可复现基准。

内容检查仅覆盖指定的敏感标识、文件类型、素材清单、引用和生成一致性。后续增加生产摘录或真实素材时，需要重新核对来源、授权和脱敏范围；当前没有为原系统声明开源许可。
